# Umzug ins private Repo

**Warum:** `Buchiarmin/Buchiarmin` ist das öffentliche Profil-Repo auf [[GitHub]] – die `README.md` erschien auf der Profilseite, der [[Obsidian]]-Vault war öffentlich lesbar. Nutzer will es privat ([[Vorlieben des Nutzers]]).

**Wie:** Nutzer legte das leere private Repo `Buchiarmin/claude-setup` an (Claude durfte keine Repos erstellen, 403). [[Claude Code]] hat die ganze History dorthin übertragen. Danach werden die Dateien per PR aus dem Profil-Repo entfernt.

**Ab jetzt:** In Sitzungen immer mit `claude-setup` arbeiten. Handy verbindet sich mit diesem Repo: [[Obsidian am Handy]].

Verwandt: [[Claude Code Plugins]], [[Obsidian als Gedächtnis]].
